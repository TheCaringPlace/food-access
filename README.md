# Food Access Points

Find food pantries, pop-ups, shelters, and soup kitchens in the region. Search by address or location name, filter by service type or day, and view nearby results on the map.

## Use the finder

1. Search for an address or choose **Location name** to search by name.
2. Filter results by location type or day of service.
3. Select a result to see its details or get directions.

## Add the finder to a website

In the page editor, add a custom HTML or embed block where the finder should appear:

```html
<food-access-map></food-access-map>
<script type="module" src="https://YOUR-FINDER-URL/assets/widget.js"></script>
```

Replace `YOUR-FINDER-URL` with the public URL where the finder is hosted, then publish the page. The host site must allow external module scripts and allow the finder URL to load its data and styles.

Use of the finder is limited to authorized domains. Open a ticket to request access for another site.
